# Aplikasi React Pertama - Modul 1.2

Aplikasi web interaktif modular yang dibangun menggunakan React dan Vite.

## Fitur Aplikasi:
- Tombol Counter interaktif berbasis state.
- Kolom input nama dengan sapaan real-time.
- Struktur kode modular terpisah di folder components.

## Cara Menjalankan Proyek:
1. Buka terminal di folder proyek.
2. Jalankan perintah: `npm run dev`
3. Akses alamat di browser: `http://localhost:5173`

# Kartu Profil Interaktif

Mini project React dan Vite untuk latihan modularisasi
komponen dan interaktivitas.

## Fitur
- Input profesi atau pekerjaan secara real-time.
- Menampilkan profesi yang sedang diketik.
- Tombol Suka dengan jumlah yang bertambah setiap diklik.
- Komponen profil dipisahkan ke file tersendiri.

## Cara menjalankan
1. Buka folder proyek di VS Code.
2. Jalankan npm install.
3. Jalankan npm run dev.
4. Buka alamat lokal yang ditampilkan terminal.

## Konsep React yang digunakan
- useState
- onChange
- onClick
- Modularisasi komponen
